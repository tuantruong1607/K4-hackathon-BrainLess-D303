# VLearn Adaptive Classroom

Frontend prototype cho một không gian học tập thích ứng, kết hợp slide bài giảng, AI tutor theo ngữ cảnh và live quiz được kích hoạt bởi admin.

## Tính năng

- Lộ trình học theo ngày và điều hướng slide
- Chế độ tự chuyển slide và xem toàn màn hình
- Chatbot Lumi phản hồi theo nội dung bài học
- Admin control để mở hoặc khóa live quiz
- Quiz nhiều câu, chấm điểm và làm lại
- Responsive cho desktop, tablet và mobile
- Dark mode theo hệ thống và hỗ trợ reduced motion

## Chạy dự án

```bash
npm install
npm run dev
```

Build production:

```bash
npm run build
```

## Công nghệ

- React 19
- TypeScript
- Vite
- Phosphor Icons
- Geist Variable Font
